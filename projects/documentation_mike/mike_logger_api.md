# Mike Logger API Documentation

## Overview
The Mike Logger API is a RESTful API that allows developers to interact with the Mike Logger application. The Mike Logger application is a tool for recording and managing audio logs. This API provides endpoints for creating, retrieving, updating, and deleting audio logs.
