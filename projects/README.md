# Mike Logger Generated Projects

This directory contains all projects automatically generated by the Mike Logger task execution system.

## Overview

When you speak tasks into Mike Logger or submit them via the dashboard, the system:

1. **Extracts tasks** from your speech/text
2. **Analyzes intent** to determine the appropriate project
3. **Executes the task** using Claude AI
4. **Creates files** in the appropriate project directory

## Current Projects

- **general/** - General tasks that don't fit specific categories
- **mike_logger/** - Tasks related to improving Mike Logger itself
- **docs/** - Documentation tasks
- **work/** - Work-related tasks
- **personal/** - Personal reminders and tasks
- **python_supercollider/** - Infinite jukebox music generation project
- **simple/** - Simple scripts and examples
- **manual_task/** - Tasks submitted via web interface

## Project Metadata

The `.project_metadata.json` file tracks:
- Creation dates
- Keywords for intelligent routing
- File counts
- Task descriptions

## How It Works

1. **Voice/Text Input** → Task is captured
2. **AI Processing** → Claude extracts actionable tasks
3. **Project Routing** → Tasks are routed to appropriate projects based on keywords
4. **Code Generation** → Claude generates the requested code/files
5. **Automatic Organization** → Files are saved in project directories

Each project is self-contained and can be copied out for use in other systems.
