# Mike Logger

## Overview
Mike Logger is a project that provides a simple and efficient way to log audio data from a microphone. It is designed to be used in a variety of applications, such as voice recording, audio analysis, and speech recognition.

## Features
- Supports multiple audio input devices (e.g., built-in microphone, USB microphone)
- Allows for real-time audio recording and logging
- Provides options for configuring audio sample rate, bit depth, and number of channels
- Includes a command-line interface (CLI) for easy integration into scripts and workflows
- Supports saving audio data in various file formats (e.g., WAV, FLAC, MP3)
- Includes a Python API for programmatic control and integration
